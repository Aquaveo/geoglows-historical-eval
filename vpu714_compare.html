What is being compared

Only gauges present in both runs are compared, because two models built on different river networks do not score the same gauges — and if the ones a model lacks are systematically the hard ones, comparing the two populations flatters it for a reason that has nothing to do with the model. Every figure below is a paired difference: same gauge, same observations, same days, only the model differs.

Where each run wins

Coloured by which run scored closer to the metric's optimum, not by how much. The size of a per-gauge difference is poorly determined; its SIGN is not, because the comparison is paired — same gauge, same observations, same days. "About equal" is a band, since a difference of 1e-9 always has a sign and colouring it would be noise.

GEOGLOWS v2 better RFS v3 sample better about equal scored by only one run

Gauges in the fourth colour exist in only one of the two runs and are not compared anywhere else on this page — they are drawn because a comparison most easily misleads by quietly omitting them.
